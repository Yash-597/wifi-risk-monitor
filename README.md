# WiFi Risk Monitor

WiFi Risk Monitor is a Windows tray-based security utility that monitors the current Wi-Fi connection and helps users identify unsafe wireless networks.

## Goal

The goal of this project is to detect open or weak Wi-Fi networks, classify connection risk, notify the user in real time, and provide configurable protection workflows for safer browsing on public networks.

## Planned Features

- Windows system tray application
- Wi-Fi security detection using Windows network information
- Risk classification for safe, risky, trusted, protected, unknown, and paused states
- Real-time Windows notifications for risky Wi-Fi
- Trusted networks management
- Event logging and log viewer
- Network details dashboard
- Simulation mode for testing open Wi-Fi detection
- VPN-aware protection modes using the user's existing VPN
- Standalone Windows executable and installer
